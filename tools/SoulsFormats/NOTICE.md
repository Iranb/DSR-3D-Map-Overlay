# SoulsFormats source subset

Upstream: https://github.com/JKAnderson/SoulsFormats

These source files are a subset of SoulsFormats used by the separate offline extraction tool. Upstream GPL-3.0 terms are retained in LICENSE. This directory is not linked into DSRMapOverlay.exe.

Local modifications, September 2026:

- A minimal .NET 10 project file with ZstdSharp.Port 0.8.1.
- Compatibility adjustment to the MSB1 collision-part reader for the installed DSR map layout.

Keep upstream source notices when distributing this directory.
